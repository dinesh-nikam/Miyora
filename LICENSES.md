# Licensing and Character Assets

Application source licensing and character asset licensing are separate. The repository must not bundle copyrighted character artwork unless distribution rights are documented and approved. A starter character such as Nezuko can only ship with properly licensed artwork or as a clearly identified user-provided/local pack; character references alone do not grant asset rights.

Each PetPack must declare creator, license, source, attribution, commercial-use permissions, redistribution permissions, and derivative-work permissions. Custom terms must be included in a readable license file. Verify license metadata and preserve attribution in the installed library and any export.

Community publication requires a creator rights attestation, license/source metadata, content report mechanism, moderation state, and takedown workflow. A report does not itself establish infringement; maintain a review and appeal process. Track asset provenance at pack-version granularity so updates do not erase prior attribution.

Third-party code and bundled dependencies require license inventory and compatibility review. Releases should include a third-party notices file and SBOM. This file does not provide legal advice or grant rights to any character, artwork, sound, font, or trademark.
